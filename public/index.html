JungleGaming

Console de testes do processador de apostas. Use para criar carteira, apostar e forçar falhas (saldo insuficiente, idempotência, moeda errada, etc.). Isto é só uma ferramenta — o desafio avalia a API e os testes, não o visual.

Saúde da API

Roteiro rápido

  1. Crie uma carteira com 1000.00
  2. Faça uma aposta (BET) de 25.00
  3. Confira o saldo e a reconciliação
  4. Repita a mesma chave → deve ser replay

Carteira

Ideias de falha

  • BET maior que o saldo → rejeitada
  • Mesma chave + valor diferente → conflito
  • Moeda USD em carteira BRL → rejeitada
  • REFUND sem BET → pendente de referência
